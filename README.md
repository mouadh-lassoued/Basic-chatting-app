# Basic Chatting App (Socket.IO)

A very simple real-time chatting application built with **Socket.IO**.

This project includes both:
- Server code
- Client code

The app broadcasts every message sent by a connected client to all other clients connected to the same server.

---

## 🚀 Features

- Real-time communication using WebSockets (via Socket.IO)
- Multiple clients can connect simultaneously
- Messages are broadcast to all connected users
- Minimal and beginner-friendly structure

---

## 🛠️ Tech Stack

- Node.js
- Socket.IO
- HTML  / JavaScript (Client side)
